第四册｜Sport 语法与词表、Erholung 导读

《新编大学德语》第四册（第二版）。以下例句为原创。

vom … bis hin zum … · 阅读时间限定

vom 和 zum 分别是 von dem、zu dem，范围两端均为第三格。bisher 表示“迄今为止”，需要结合上下文确定时间范围。

Vom ersten Entwurf bis hin zum fertigen Text ist viel Arbeit nötig.

无宾语主动句的名词化

事件名词作中心词，原主语可化为属格定语。原句的时间状语仍可保留。

Die Preise stiegen im Mai. → der Anstieg der Preise im Mai

及物动词、被动和形容词的名词化

及物动词的受事可化为属格，施事可用 durch + 第四格；过程被动的主语也是受事。sein + 形容词可转成对应的抽象名词。

Die Stadt eröffnet die Bibliothek. → die Eröffnung der Bibliothek durch die Stadt

feststehen · verkünden · der Kandidat

feststehen 表结果已定；verkünden 表发布结果，可直接接第四格；Kandidat 是弱变化阳性名词。

Es steht fest, wer gewonnen hat. Das Ergebnis wird morgen verkündet.

für + A vorgesehen sein · knapp gewinnen

vorgesehen sein 表预定安排；时间也可用 für。knapp 描述差距小，既可修饰 gewinnen，也可修饰 verlieren。

Für nächste Woche ist eine weitere Abstimmung vorgesehen.

Einfluss auf + A ausüben · auf jdn. zugehen

ausüben 可分，用 Einfluss 作宾语、auf 标作用对象。zugehen 的方向搭配用 auf + 第四格。

Die Werbung übt Einfluss auf unser Kaufverhalten aus.

jdn. von + D ablenken · unterzeichnen

ablenken 中被转移注意力的人用第四格，原先关注的事用 von；unterzeichnen 的第二分词为 unterzeichnet。

Die Nachrichten auf dem Handy lenken mich vom Lesen ab.

本单元围绕恢复精力、劝告表达与复合名词展开。
