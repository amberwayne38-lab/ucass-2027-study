Mode：虚拟式、es 与词汇

《新编大学德语》第三册。例句为原创。

礼貌请求：Wären Sie so freundlich, …?

虚拟式将命令缓和成请求，具体动作由 zu 不定式交代。

Wären Sie so freundlich, mir das Formular zu schicken?

指代代词 es / 非人称主语 es

代词可回指中性名词；天气表达中 es 无具体所指，换句首时仍保留。

Ich habe das Buch gelesen. Ich empfehle es dir. Heute regnet es.

句首占位 es 与真正主语

句首占位不决定谓语单复数。真正主语前置时占位词消失。

Es fehlen zwei Seiten. → Zwei Seiten fehlen.

das Kleidungsstück / das Tuch

复合词 Kleidungsstück 以 Stück 决定冠词；Tuch 的常见复数为 Tücher。

Im Regal liegen drei bunte Tücher.

beeinflussen + A / einen Einfluss auf + A haben

同一个影响关系可用直接宾语或名词搭配表达。

Die Musik beeinflusst meine Stimmung.

Aufmerksamkeit erregen / sich von + D distanzieren

erregen 是引起，distanzieren 可用于表达与观点划清界限。

Sie distanziert sich von dieser Aussage.

etw. als … bezeichnen / mit + D verzieren

前者给事物定性，后者以 mit 引出装饰材料。

Viele bezeichnen das Werk als einen Klassiker.

eine Vielzahl an + D / jdm. erlauben, … zu …

Vielzahl 用于引出数量多、种类丰富的对象；erlauben 的受许可者用三格。

Die Ausstellung zeigt eine Vielzahl an historischen Entwürfen.
