第四册 · Einheit 1 Lernen｜印刷页24—28

来源：《新编大学德语》第四册（第二版），原PDF第27—31页，对应印刷页24—28。原书第24—25页为 Meine lieben Fehler 练习，26—27页为 Wortbildung durch Ableitung 构词法，28页为词汇表开头。本批20组结构及考点，包含教材举例和原创应用例句。第三列为根据教材内容原创的说明，第四列全部为原创例句，非教材原句。

#教材对应结构/词族构词/语法与考研用法原创应用例句
1das Schreiben / das Lernen / das Leben动词不定式名词化；中性名词，首字母大写Das regelmäßige Lernen hilft mir.
2der Versuch / der Anruf / der Flug词干派生名词，不能机械从动词推断性别Der Versuch ist gelungen.
3die Änderung / die Prüfung / die Übung-ung 构成阴性名词Die Prüfung erfordert Vorbereitung.
4die Frage / die Sprache / die Bitte部分词干加 -e，名词阴性Ihre Frage ist wichtig.
5das Erlebnis / das Ergebnis / das Ereignis-nis 构成中性名词；注意词形变化Das Ergebnis überrascht mich.
6das Gefühl / das Gepäck / das GesprächGe- 名词化；不能推断所有 Ge- 名词都为中性Das Gespräch war hilfreich.
7die Definition / die Diskussion / die Information-ion 构成阴性名词Die Diskussion war produktiv.
8die Tiefe / die Weite / die Länge形容词词干 + -e，构成阴性名词Die Länge des Textes ist angemessen.
9die Gesundheit / die Wahrheit / die Freiheit形容词 + -heitGesundheit ist wichtig.
10die Möglichkeit / die Lesbarkeit / die Fähigkeit形容词 + -keitDie Lesbarkeit des Textes ist gut.
11die Genauigkeit / die Neuigkeit / die Arbeitslosigkeit-igkeit 构成阴性名词Die Genauigkeit ist entscheidend.
12die Aktivität / die Nationalität / die Neutralität-ität 构成阴性名词Ihre Aktivität nimmt zu.
13sprachlich / schriftlich名词 + -lich 构成形容词Die schriftliche Prüfung ist schwer.
14fleißig / fähig名词词干 + -ig 构成形容词Sie ist sehr fleißig.
15politisch / typisch名词词干 + -isch 构成形容词Das ist ein typisches Beispiel.
16mit unbekannten Wörtern umgehenmit + D；学习陌生词汇的处理方式Man muss mit unbekannten Wörtern sinnvoll umgehen.
17die Bedeutung mit Hilfe des Kontextes erschließenmit Hilfe + G；erschließen = 根据线索推断Die Bedeutung lässt sich aus dem Kontext erschließen.
18Wortbildungskenntnisse verwenden运用构词法知识，资料练习页24Wir verwenden unsere Wortbildungskenntnisse.
19produktiv mit Fehlern umgehenmit + D；错误处理表达Man sollte produktiv mit Fehlern umgehen.
20Fehler analysieren und begründen分析并说明错误原因Versuchen Sie, die Fehler zu analysieren und zu begründen.

迁移训练（原创）

  1. 将动词 lernen、schreiben 名词化，并说明冠词。
  2. 解释 die Fähigkeit、die Arbeitslosigkeit 的构词方式。
  3. 翻译：我们应该根据上下文推断陌生词的意思。
  4. 将 Man muss Fehler analysieren. 改写为带有 zu-Infinitiv 的建议句。
